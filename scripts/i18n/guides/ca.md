# ca translation guide

Apply `default.md` first, then these Catalan rules.

- Use standard Catalan, not Spanish with Catalan spelling. Avoid Spanish calques and regionally marked Valencian/Balearic wording unless the existing locale establishes it.
- Keep a friendly, direct UI register; use consistent second-person or impersonal phrasing rather than switching forms.
- Preserve Catalan accents, apostrophes, and elisions (`l’`, `d’`) and use Catalan punctuation spacing naturally.
- Use Catalan terms for groups, members, expenses, shares, and settlements consistently across the bundle.
- Exclusive settlement term: *liquidació* (noun) and *liquidar* (verb). Never *reemborsament*.
- Respect grammatical gender and number, but prefer neutral rephrasing when a label does not need to name a person.
