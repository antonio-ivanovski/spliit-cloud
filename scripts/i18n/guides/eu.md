# eu translation guide

Apply `default.md` first, then these Basque rules.

- Use standard Euskara (Basque), not Spanish or French with Basque-looking endings. Avoid unnecessary loans when a normal Basque term exists.
- Remember that Basque is agglutinative: attach cases and postpositions naturally instead of copying English preposition order.
- Keep a neutral, approachable UI register and avoid adding gender where Basque does not require it.
- Preserve correct diacritics and natural Basque punctuation. Keep placeholders and rich-text tags in positions that do not break the surrounding word.
- Use one consistent term for each Spliit concept, checking nearby translations when a compound can be formed more than one way.
- Exclusive settlement term: _zor-kitapen_ (noun, forms _zor-kitapena_/_zor-kitapenak_/_zor-kitapeneko_) and _kitatu_ (verb, _kitatu_/_kitatuta_/_kitzeko_). Never _itzulketa_, _likidazio_/_likidatu_, _konpentsazio_/_konpentsatu_, or Spanish _reembolso_. Do not use bare _Kitzea_/_Kitapen_ for settlement.
