# hi-IN translation guide

Apply `default.md` first, then these Hindi (India) rules.

- Use standard Hindi in Devanagari with a polite, approachable `आप`/impersonal UI voice (never `तुम`); address errors with `कृपया पुनः प्रयास करें।` (use `पुनः`, not `पुन:`). Avoid Hinglish and Sanskritized words that ordinary users would not recognize. `Spliit Cloud` is a brand — keep it as-is (never `Spliit Cloud आयात`).
- Use Indian Hindi vocabulary and natural postposition order; do not copy English prepositions or Urdu script conventions.
- Maintain correct gender and number agreement, but rephrase to avoid unnecessary gender assumptions in labels and accessibility text.
- Use the Devanagari danda (`।`) consistently in sentence-final UI text and preserve vowel marks; keep Latin brands, URLs, and placeholders intact. Prefer `एक्सपोर्ट` over `निर्यात` for the file export concept (the app uses both but file contexts use `एक्सपोर्ट`). English `ship` in product copy means release, not `जहाज`.
- Fill locale-specific plural forms naturally and preserve the exact amount, percentage, or count represented by the app.
- Exclusive settlement term: _निपटान_ (noun) and _निपटाना_ (verb). Never _प्रतिपूर्ति_ or _रिफंड_ for this concept. For unsettled states use `निपटान बाकी` / `अनिपटाई शेष राशि`, not `असंतुलित शेष राशि` (means unbalanced). Income placeholder is `वेतन या वापसी` (repayment), not settlement; the only allowed `वापसी` outside settlement.
