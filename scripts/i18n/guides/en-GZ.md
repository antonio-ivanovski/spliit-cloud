# en-GZ translation guide

Apply `default.md` first, then these Gen-Z English rules.

- This is an opt-in playful variant of en-US, not the default English locale. Keep the meaning and action unmistakable.
- Use contemporary, widely understandable internet language sparingly. A little personality is useful; forcing slang into every label is not.
- Lowercase, casual phrasing, and gen-z can be used when terms fit the surrounding bundle, but do not make the UI look careless or unprofessional.
- Avoid strong use of slang, sarcasm, memes, or ambiguous jokes in money amounts, balances, destructive actions, validation errors, security messages, or accessibility labels. Ok to use, but the meaning behind shall remain clear and unambiguous.
- Keep the same US English spelling, number conventions, placeholder names, rich-text tags, and financial precision as en-US.
- Prefer a clear plain-English fallback when a slang term could age quickly, be misunderstood internationally, or obscure what the user must do.
- Brand is `Spliit Cloud` (never `Spliit Cloud import` in source pickers). Income placeholder `salary or refund vibes` is repayment — the only allowed `refund`.
- Do not leave trailing spaces in values; trim all strings before saving.
- Exclusive settlement term: settlement / settle up. Never reimbursement or refund for this concept.
