# id translation guide

Apply `default.md` first, then these Indonesian rules.

- Use standard Bahasa Indonesia for Indonesia with a friendly, neutral UI voice. Avoid Malaysian vocabulary and overly formal bureaucratic language.
- Indonesian has no grammatical gender or articles; do not invent gendered pronouns. Omit `Anda` when an impersonal label is more natural, and use it consistently when direct address is needed.
- Use natural Indonesian affixes and word order rather than literal English syntax. Keep labels concise.
- Plurality is often expressed by context or a number, but every required plural key still needs a natural translation.
- Preserve Indonesian capitalization, diacritics, punctuation, and the app’s exact numeric meaning.
- Exclusive settlement term: _pelunasan_ (noun) and _lunasi_ (verb). Never _reimbursement_ or _pengembalian dana_ for this concept.
