# id translation guide

Apply `default.md` first, then these Indonesian rules.

- Use standard Bahasa Indonesia for Indonesia with a friendly, neutral UI voice. Avoid Malaysian vocabulary and overly formal bureaucratic language.
- Indonesian has no grammatical gender or articles; do not invent gendered pronouns. Omit `Anda` when an impersonal label is more natural, and use it consistently when direct address is needed.
- Use natural Indonesian affixes and word order rather than literal English syntax. Keep labels concise.
- Plurality is often expressed by context or a number, but every required plural key still needs a natural translation.
- Preserve Indonesian capitalization, diacritics, punctuation, and the app’s exact numeric meaning. Brand stays as `Spliit Cloud` (never `Impor Spliit Cloud` in source pickers). Fixed-rate import uses a single exchange rate per currency pair from Frankfurter (not "Kurang akurat/tetap nol bersih"). Itemized split is `Per item`.
- Exclusive settlement term: _pelunasan_ (noun) and _lunasi_ (verb). Never _reimbursement_ or _pengembalian dana_ for this concept. Unsettled states use `belum dilunasi`/`dilunasi`, not generic `belum diselesaikan`/`penyelesaian`; also `Tersembunyi` alone is not a settlement label — use `Pelunasan tersembunyi` / `Tampilkan pelunasan`. Income placeholder `Gaji atau pengembalian dana` is repayment, not settlement, and is the only allowed _pengembalian dana_.
