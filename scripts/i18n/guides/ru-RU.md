# ru-RU translation guide

Apply `default.md` first, then these Russian rules.

- Use standard Russian for Russia in a friendly neutral `ты`/impersonal UI voice; do not switch to formal `вы` without context. Impersonal infinitives (`Используйте`, `Скажите`) are acceptable for instructional hints.
- Decline nouns, names, and adjectives in the correct case and gender. Rephrase when a short label can avoid an unnecessary gender assumption.
- Respect Russian plural categories and count-dependent case changes; do not copy one noun form into every plural key.
- Use Cyrillic punctuation and Russian quotation conventions (`«»`, `—`), and keep terminology distinct from Ukrainian or Belarusian. Balance is `баланс`/`балансы` (never `остаток`/`остатки` which means inventory remainder). Use `ё` consistently.
- Preserve exact amounts, percentages, and placeholder names while keeping action labels concise. Itemized split is `По позициям` (`Доля каждого участника рассчитывается из отдельных позиций расхода.`). Fixed-rate import uses a single exchange rate per currency pair from Frankfurter; income placeholder is `Зарплата или возврат` (not a settlement). Brand is `Spliit Cloud` (never `Импорт Spliit Cloud` in source pickers).
- Exclusive settlement term: _расчёт_ (noun) and _рассчитаться_ (verb). Never _возмещение_ or _компенсация_ for this concept. For unsettled states use `нерассчитанные балансы`/`нерассчитанными`/`рассчитан`, not bureaucratic `неурегулированные остатки`/`урегулированы`.
