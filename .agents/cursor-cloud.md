# Cursor Cloud agent instructions

These notes apply only to Cursor Cloud agents running in the provisioned VM. They are not relevant to local human development.

Standard setup/commands live in [`README.md`](../README.md) and [`CONTRIBUTING.md`](../CONTRIBUTING.md) (`bun install`, `bun dev:up`, `bun prisma-migrate`, `bun dev`, `bun run check`, `bun run test`). The startup update script already runs `bun install`; `bun` and Docker are preinstalled in the VM image. The notes below are the non-obvious gotchas specific to this environment (respect the AGENTS.md hard rule: only start `bun dev:up` / `bun dev` when the user asks).

- Docker is NOT auto-started. Before `bun dev:up`, start the daemon once per session: `sudo dockerd > /tmp/dockerd.log 2>&1 &` (wait ~8s). If you hit a docker socket permission error, run `sudo chmod 666 /var/run/docker.sock`.
- `bun dev:up` pre-creates `./storage/*` owned by your user and runs the service containers as that uid/gid, so no post-up `chown` is needed. If `storage/` predates the fix and is root-owned, one-time: `sudo chown -R $(id -u):$(id -g) storage`, then `bun dev:up` again.
- Running the app: `bun dev` serves web, api, and worker admin through portless (`https://spliit.localhost`, `https://api.spliit.localhost`, `https://jobs.spliit.localhost`; needs the proxy up: `sudo portless proxy start -p 443 --https`). Without portless, prefix `PORTLESS=0` to fall back to plain ports (web `:3000`, api `:3001`, worker admin `:3003`) and override the https URL envs back to `http://localhost:300x`. The optional MCP app (`@spliit/mcp`, `https://mcp.spliit.localhost`) and Cloudflare relay (`@spliit/webhook-relay`, `https://relay.spliit.localhost`) are opt-in: `bun --filter @spliit/mcp dev:mcp` and `bun --filter @spliit/webhook-relay dev:relay`. To run MCP, set valid `MCP_PUBLIC_URL`/`MCP_API_URL`/`MCP_WEB_URL` (portless-https defaults are for Inspector-only testing; ChatGPT/Claude need public cloudflared tunnel URLs; local Node-to-API calls may need `NODE_EXTRA_CA_CERTS` pointing at the portless CA — see `.env.example`).
- Signup requires email verification (`requireEmailVerification: true`); open/click the verification link in MailDev at http://localhost:1080. Other local UIs: MaxIO S3 at http://localhost:9000/ui/, pg-boss dashboard at http://localhost:3004, API health at http://localhost:3001/health/readiness.
- Formatting (`oxfmt`, used by `bun run check` / `check-formatting` / `format`) loads `oxfmt.config.ts` via Node's TS support and needs Node ≥ 22.18.0. The daemon's default `node` on `PATH` (`/exec-daemon/node`) is older and makes those commands fail with "TypeScript config files require Node.js …". A newer Node (22.22.2) is installed via nvm; prepend it before running formatting, e.g. `PATH="$HOME/.nvm/versions/node/v22.22.2/bin:$PATH" bun run check`. `oxlint`/`tsc`/`vitest`/build/dev are unaffected.
