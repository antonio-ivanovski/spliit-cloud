Spliit Cloud 2.7.0에서 영수증 스캔을 처음부터 끝까지 개편했습니다. 스캔은 약 5배 빨라지고 카테고리 제안은 더 똑똑해졌으며, 이제 사진이 아닌 영수증도 읽을 수 있습니다. 자세한 내용은 [v2.7.0](https://github.com/antonio-ivanovski/spliit-cloud/releases/tag/v2.7.0) 노트에서 확인하세요.

## 더 빠른 스캔

이제 영수증은 AI가 읽기 전에 전용 텍스트 추출 단계를 먼저 거치므로, 느린 모델이 사진을 읽는 대신 빠른 모델이 구조화를 맡습니다. 저희 측정에서는 항목 10개짜리 영수증이 약 80초에서 약 14초로 줄었고, 작은 영수증은 보통 6초 정도에 끝납니다. 카테고리 분류도 전체 지출 내역을 바탕으로 판단하는 빠른 결정 모델로 옮겨 제안이 더 잘 맞을 거예요.

## 사진 그 이상

이제 PDF 청구서도 스캔할 수 있습니다. 디지털 PDF는 바로 읽고 촬영본은 자동으로 전환되며, TXT, CSV, DOCX, ODT 파일도 지원합니다. 수량에 소수도 지원하므로, 1.5kg 같은 저울 상품도 반올림되지 않고 적힌 그대로 들어옵니다.

## 합계가 맞지 않으면 직접 고르세요

스캔한 항목 합계가 영수증 합계와 다르면 추측하지 않고 미리보기에서 어느 합계가 맞는지 묻습니다. 작은 반올림 차이는 "반올림" 항목을 보여주고 영수증 합계를 미리 선택해 두며, 차이가 크면 경고를 띄우고 명시적인 "기타" 항목을 제공해요. 편집 폼에서 언제든 바로잡을 수 있습니다.

## 잘못 읽은 부분을 알려 주세요

이 새로운 파이프라인은 이미 Spliit Cloud의 모든 스캔에 적용되고 있어서 여러분의 영수증이 진짜 테스트가 됩니다. 항목을 잘못 읽거나 카테고리를 틀리게 고르거나 합계가 이상하면, 공유할 수 있는 경우 영수증과 함께 [신고해 주세요](https://github.com/antonio-ivanovski/spliit-cloud/issues/new?template=bug_report.yml).
