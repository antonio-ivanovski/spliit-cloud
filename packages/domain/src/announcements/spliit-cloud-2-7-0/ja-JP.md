Spliit Cloud 2.7.0 ではレシートスキャンを全面的に刷新しました。スキャンは約5倍高速になり、カテゴリの判定も賢くなり、写真以外のレシートにも対応しました。詳細は [v2.7.0](https://github.com/antonio-ivanovski/spliit-cloud/releases/tag/v2.7.0) のリリースノートをご覧ください。

## 高速なスキャン

レシートは AI が読み取る前に専用のテキスト抽出ステップを通るようになり、写真の読み取りという重い処理ではなく、高速なモデルが構造化を担います。私たちの計測では、品目10点のレシートが約80秒から約14秒に短縮され、小さなレシートでは6秒ほどで完了することもよくあります。カテゴリ判定も、支出履歴全体を踏まえた高速な判断モデルに移行したため、より的確な提案が期待できます。

## 写真だけじゃない

PDF の請求書もスキャンできるようになりました。デジタルの PDF は直接読み取り、撮影したものは自動で切り替えます。TXT、CSV、DOCX、ODT ファイルにも対応しています。数量は小数にも対応し、1.5 kg のような計量品目は丸められず、印字どおりに取り込まれます。

## 合計が合わないときはあなたが選ぶ

スキャンした明細の合計がレシートの合計と合わない場合、推測で決めずに、プレビューで正しい合計を選べるようになりました。小さな丸め誤差では「丸め調整」の行が表示され、レシートの合計があらかじめ選択されます。差が大きい場合は警告とともに明示的な「その他」の行が表示され、編集フォームでいつでも修正できます。

## 読み間違いを教えてください

この新しい処理は Spliit Cloud 上のすべてのスキャンにすでに適用されており、実際のレシートこそがテストになります。品目の読み間違い、カテゴリの誤判定、合計のおかしな点に気づいたら、共有できる場合はレシートを添えて[報告](https://github.com/antonio-ivanovski/spliit-cloud/issues/new?template=bug_report.yml)してください。
