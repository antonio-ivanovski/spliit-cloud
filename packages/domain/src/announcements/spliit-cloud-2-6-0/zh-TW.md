Spliit Cloud 2.6.0 為應用程式帶來唯讀離線功能：沒有網路連線時，也能繼續查看您的群組。這是唯讀離線的基礎——待此階段穩定後，將陸續支援包含建立支出在內的完整離線寫入功能。詳情請參閱 [v2.6.0](https://github.com/antonio-ivanovski/spliit-cloud/releases/tag/v2.6.0) 版本說明。

## 離線狀態下可以做的事

- 開啟群組，瀏覽包含留言的完整支出紀錄、餘額、成員名單、子群組指派、分攤預設、預算、群組設定及近期動態。
- 清單會從裝置上的本機副本即時開啟，並在重新連線後就地合併新的變更，因此在連線緩慢時也會感覺快上許多。
- 依照新增的逐步指引，將 Spliit Cloud 作為應用程式安裝到您的裝置上。

## 仍需要網路連線的操作

建立或編輯支出、檔案，以及超出已下載範圍的較早動態仍需要網路連線，餘額過期時會顯示提醒。重新連線後若顯示異常，重新整理即可取得最新狀態。

## 協助我們修正問題

離線模式是新功能，在離線寫入功能推出前需要經過真實情境的測試；為實現此功能，用戶端經歷了大規模重構，因此線上模式也可能出現問題。如果您發現任何異常，不論是在離線或線上狀態——例如清單無法載入、重新連線後控制項仍停用，或過期餘額一直未清除——請附上您的操作、當時是否處於離線狀態，以及預期的結果[回報問題](https://github.com/antonio-ivanovski/spliit-cloud/issues/new?template=bug_report.yml)。有一點可以放心：伺服器端計算支出的方式沒有任何改變——餘額、分攤與結算的計算方式與以往完全相同。每一則回報都有助於我們修復剩餘的問題。
