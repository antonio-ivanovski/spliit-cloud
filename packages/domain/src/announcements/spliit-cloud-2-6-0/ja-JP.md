Spliit Cloud 2.6.0 では読み取り専用のオフライン対応が追加され、接続がなくてもグループを閲覧できるようになりました。これは読み取りオフラインの基盤であり、この段階が安定したら、支出の作成を含む完全なオフライン書き込みに順次対応します。詳細は [v2.6.0](https://github.com/antonio-ivanovski/spliit-cloud/releases/tag/v2.6.0) のリリースノートをご覧ください。

## オフラインでできること

- グループを開いて、コメント付きの完全な支出履歴、残高、メンバーリスト、サブグループの割り当て、分割プリセット、予算、グループ設定、最近のアクティビティを閲覧できます。
- リストはデバイス上のコピーから瞬時に開き、再接続時に新しい変更をその場で統合するため、接続が遅い場合も大幅に高速に感じられます。
- 新しいステップバイステップのガイドに沿って、Spliit Cloud をデバイスにアプリとしてインストールできます。

## 接続がまだ必要な操作

支出の作成や編集、ファイル、ダウンロード範囲外の古いアクティビティには引き続き接続が必要で、残高が古い場合は警告が表示されます。再接続後に表示がおかしい場合は、更新すると最新の状態を取得できます。

## 不具合の解消にご協力ください

オフラインモードは新機能であり、書き込みオフラインの提供前に実際の利用でのテストが必要です。これを実現するためにクライアント側で大規模なリファクタリングが行われたため、オンラインモードでも不具合が発生する可能性があります。オフライン・オンラインを問わず、リストが読み込めない、再接続後も操作が無効のままになる、古い残高が解消されないなど、おかしな点に気づいたら、何をしていたか、そのときにオフラインだったかどうか、期待した動作とあわせて[報告](https://github.com/antonio-ivanovski/spliit-cloud/issues/new?template=bug_report.yml)してください。1点ご安心ください。サーバー側での支出の計算方法に変更はありません。残高、分割、精算はこれまでどおり正確に計算されます。すべてのご報告が残りの不具合の特定に役立ちます。
