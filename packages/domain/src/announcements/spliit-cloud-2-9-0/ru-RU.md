Spliit Cloud 2.9.0 добавляет встроенные импорты Tricount и Settle Up, так что существующие группы переезжают вместе с тобой. Подробности — в заметках к [v2.9.0](https://github.com/antonio-ivanovski/spliit-cloud/releases/tag/v2.9.0).

## Из Tricount — двумя способами

Вставь ссылку для общего доступа Tricount — группа подтянется на сервере, запрос GDPR не нужен, — или перетащи GDPR-выгрузку в CSV. Выгрузки с несколькими группами покажут выбор с числом участников и расходов в каждой группе, а каждая группа по очереди пройдёт сопоставление и конвертацию валюты.

## Из Settle Up — один CSV

Отправь себе CSV с историей группы из Settle Up на почту, а затем перетащи его на вкладку Settle Up. Расчёты и доходы переносятся вместе с группой, категории сопоставляются с категориями Spliit, а суммы пересчитываются в твою целевую валюту по историческим курсам на момент подтверждения.

## Не получается найти экспорт?

У каждого поля ввода импортёра теперь есть собственное пошаговое руководство, которое отвечает ровно на тот вопрос, что возникает в этом месте, — где взять ссылку или откуда взять файл.
