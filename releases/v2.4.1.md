Welcome to `v2.4.1`! A polish release led by customizable group tabs — the tab bar now leads with Expenses, Balances, Activity, and Members, and you can set your own tab order and hide tabs you don't use from Account settings — plus quality-of-life improvements for itemized expenses and the mobile time picker, and a batch of navigation and display fixes. No breaking changes.

## What's Changed

### 🚀 Features

- Group tabs now lead with Expenses, Balances, Activity, and Members, and you can set your own tab order — including hiding tabs you don't use — from Account settings. Thanks @KihtrakRaknas for opening [#139](https://github.com/antonio-ivanovski/spliit-cloud/issues/139) ([`3b00a2d0`](https://github.com/antonio-ivanovski/spliit-cloud/commit/3b00a2d07d1caf268d5f7bcca4ba17f8ee083a17) by @antonio-ivanovski)
- Itemized expenses now show “Itemized” as the selected “Split between” option with each person’s calculated share, and the expense details list who each item is assigned to with an expandable per-person breakdown. Thanks @KihtrakRaknas for opening [#135](https://github.com/antonio-ivanovski/spliit-cloud/issues/135) and [#146](https://github.com/antonio-ivanovski/spliit-cloud/issues/146) ([`f0d88e37`](https://github.com/antonio-ivanovski/spliit-cloud/commit/f0d88e3798e599f629d79cf603f6b840e7d8f191), [`29e26eb7`](https://github.com/antonio-ivanovski/spliit-cloud/commit/29e26eb71789483940e89dbc8ddd201cd9e02cc6) by @antonio-ivanovski)
- The mobile expense time picker now uses large scrollable hour and minute wheels with Now, Morning, Midday, and Evening shortcuts instead of the cramped time grid. Thanks @KihtrakRaknas for opening [#140](https://github.com/antonio-ivanovski/spliit-cloud/issues/140) ([`82312753`](https://github.com/antonio-ivanovski/spliit-cloud/commit/82312753e35e607203d86dc800c22ff43588cd0b) by @antonio-ivanovski)
