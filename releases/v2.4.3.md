Welcome to `v2.4.3`! A richer group activity feed, more personal expense notifications, and a handful of UI and security fixes.

## What's Changed

### 🚀 Features

- Group activity feed now records emoji and color changes, subgroup create/rename/delete, shared split-preset changes and group defaults, newly added participants, and friend invite creation/accepts. Expense comments no longer create feed rows but still send notifications ([`fab6807c`](https://github.com/antonio-ivanovski/spliit-cloud/commit/fab6807c2f5ac46ac53bc15c51054448b15fc2a1) by @antonio-ivanovski)
- Expense added/updated email and push notifications now include your personal share ("You owe X · You paid Y", or "You lent/borrowed X" for settlements). Thanks @KihtrakRaknas for opening [#148](https://github.com/antonio-ivanovski/spliit-cloud/issues/148) ([`85ef0fd9`](https://github.com/antonio-ivanovski/spliit-cloud/commit/85ef0fd963851c733de7a60bf3c177eda305b7f8) by @antonio-ivanovski)
- Feedback reports now include the release version in diagnostics ([`e46a78bb`](https://github.com/antonio-ivanovski/spliit-cloud/commit/e46a78bbf6d4e06380418c39139ea3187b2f2336) by @antonio-ivanovski)

### 🐛 Bug fixes

- Expense list no longer flickers and replays its entrance animation on first load after app start ([`8baaa80c`](https://github.com/antonio-ivanovski/spliit-cloud/commit/8baaa80cd9117f91f80bbd48fbe65f09d473991f) by @antonio-ivanovski)
- Friend, member, and import dropdowns now keep showing names instead of raw IDs after selection ([`93625f27`](https://github.com/antonio-ivanovski/spliit-cloud/commit/93625f275595c4c10225d6f90c3a28f163da85e8) by @antonio-ivanovski)
- `AI_SYSTEM_ONE_BASE_URL` now requires HTTPS, except for local loopback development (`http://localhost`, `http://127.0.0.1`). A remote plaintext HTTP endpoint fails boot instead of sending the bearer key and expense context in cleartext — switch those endpoints to HTTPS ([`2d811bd1`](https://github.com/antonio-ivanovski/spliit-cloud/commit/2d811bd12b2f041b4debb4450a8936a56d41d387) by @antonio-ivanovski)
- Opening an expense from the activity tab now shows the preview over the activity feed and keeps your scroll position, including after editing. Thanks @KihtrakRaknas for opening [#142](https://github.com/antonio-ivanovski/spliit-cloud/issues/142) ([`36e72598`](https://github.com/antonio-ivanovski/spliit-cloud/commit/36e72598ff74864d73ab65d2090fa1cf19ca3a93) by @antonio-ivanovski)
