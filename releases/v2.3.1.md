Welcome to `v2.3.1`! A hotfix for the production API crash on startup — if you missed the big one, catch up on the [v2.3.0 release notes](https://github.com/antonio-ivanovski/spliit-cloud/releases/tag/v2.3.0).

## Highlights

- API starts up again in production

### API starts up again in production

The v2.3.0 images crashed on boot with `tsyringe requires a reflect polyfill`: passkey support pulls in `@peculiar/x509` via `@simplewebauthn/server`, and the bundled production server dropped the `reflect-metadata` side effect that the unbundled dev server gets for free. The entry points now import the polyfill first, so the API (and worker) boot cleanly again.

## What's Changed

### 🐛 Bug fixes

- Fixed the production API crashing on startup with `tsyringe requires a reflect polyfill` by importing `reflect-metadata` first in the API, worker, and OpenAPI-generator entry points and declaring it as a direct dependency (`328a954a` by @antonio-ivanovski)
