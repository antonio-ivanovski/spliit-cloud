Welcome to `v2.6.2`! This patch adds end-to-end coverage for the core flows and fixes expense correctness and offline dashboard ordering, with light UI consolidation and consistent app copy.

## What's Changed

### 🚀 Features

- Added automated end-to-end coverage for the core sign-in, group, expense, and balance flows, so regressions in these journeys are caught before they reach you ([`52cc4ee2`](https://github.com/antonio-ivanovski/spliit-cloud/commit/52cc4ee2351f8d2e1888ac5ea7d3741d663b021a) by @antonio-ivanovski)
- Consolidated borders and radii for a slightly more consistent look, with small type-scale and dark-mode cleanups ([`d2a7c14a`](https://github.com/antonio-ivanovski/spliit-cloud/commit/d2a7c14a856c6a1241ff8a4c390bc88728ec4352) by @antonio-ivanovski)

### 🐛 Bug fixes

- Fixed the offline dashboard so starred groups stay on top and groups, friends, balances, and actions appear in the same order as online, with create, import, scan, and all-expenses actions shown disabled ([`37c075e3`](https://github.com/antonio-ivanovski/spliit-cloud/commit/37c075e375bd212cc799f0d6c123f6ed9376c6df) by @antonio-ivanovski)
- Fixed editing a foreign-currency expense overwriting its conversion rate: the stored exchange rate is now kept when the currency and date are unchanged, and only re-fetched when they change. Thanks @KihtrakRaknas for opening [#155](https://github.com/antonio-ivanovski/spliit-cloud/issues/155) ([`8267388d`](https://github.com/antonio-ivanovski/spliit-cloud/commit/8267388d27f5b9ae23ff4daf481a8d61ad3ec4a5) by @antonio-ivanovski)
- Fixed non-itemized expenses with line items showing incorrect per-item attribution: item splits are now hidden unless the expense uses an itemized split, and switching to itemized seeds items from the expense split instead of all group members. Thanks @KihtrakRaknas for opening [#154](https://github.com/antonio-ivanovski/spliit-cloud/issues/154) ([`be6194f7`](https://github.com/antonio-ivanovski/spliit-cloud/commit/be6194f7396a144106b768165507ee230ba066d8) by @antonio-ivanovski)
- Fixed app copy referring to our app as plain "Spliit": user-visible strings now consistently say "Spliit Cloud" across English source, all locales, emails, and docs, while "Spliit" remains only for the original upstream project and its import source ([`b73935cc`](https://github.com/antonio-ivanovski/spliit-cloud/commit/b73935ccc556233cddc6723b87ef21d6c7d36b7d) by @antonio-ivanovski)
