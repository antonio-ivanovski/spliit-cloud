# Share expenses with friends & family

Spliit Cloud is a free, open-source, community-maintained app for tracking shared expenses and settling up. Sign in once to protect your data and keep your expense history available across devices.

## What you can do

- **Groups + sync**: Create groups for trips, roommates, events, and gifts, and keep them synced across devices.
- **Expenses + receipts**: Add expenses, attach receipt images, and create daily, weekly, or monthly recurring costs.
- **Advanced split**: Split equally, by percentage, by shares, or by exact amount.
- **Balances**: See who paid what and settle up with the minimum number of transfers.
- **Categories**: Assign categories so shared spending stays easy to scan.
- **Accounts**: Your groups are tied to your account, so history survives device changes.

## Spliit Cloud vs related projects

- **Spliit Cloud requires an account.** Unlike the original anonymous `spliit.app` flow where anyone with a link could edit a group, Cloud groups are synced and secured by your account. Use Cloud when you want history, sync, and access control.
- **Self-hosting still exists.** The project stays open source: you can run your own instance with Docker instead of using the hosted Cloud. Import an existing `spliit.app` group into Cloud when you are ready to move.
- **Not Spliiit.** Spliit (expense splitting) is unrelated to Spliiit, the co-subscription marketplace for sharing streaming bills.
- **Splitwise alternative.** Spliit Cloud is a privacy-focused, ad-free, community-maintained alternative to Splitwise for friends, roommates, and travelers. No advertising trackers in the app; see the privacy notice for details.

## Frequently asked questions

**Is Spliit Cloud free?**
Yes. Spliit Cloud is free and community-maintained. Optional donations cover hosting and development.

**Do participants need an account?**
Group owners sign in to create and sync groups. What guests can do depends on the invitation; the owner’s account always keeps the authoritative history.

**Is my data sold or used for ads?**
No. The project does not sell personal data and runs no third-party advertising trackers in the app.

**Where is the status page?**
Live status for the Spliit Cloud App and API is published at https://status.spliit.cloud/.
