# Support

Last updated: September 30, 2026

Spliit Cloud is a non-commercial, community-maintained project. For help with your account, groups, or expenses, contact us and include enough detail to reproduce the issue.

## Contact us

Email [contact@spliit.cloud](mailto:contact@spliit.cloud) from the address you use to sign in. Include what you were trying to do, what happened instead, and the group name or expense title when relevant. Never send passwords, recovery links, or one-time codes.

We aim to reply within a few days. Spliit Cloud has no paid support tier and no guaranteed response time.

## Before writing

- Service status: check [status.spliit.cloud](https://status.spliit.cloud/) for ongoing incidents.
- Bugs and ideas: open an issue from the [feedback page](https://spliit.cloud/feedback), which also collects the browser diagnostics developers need.
- Privacy requests (access, correction, deletion, export): email [privacy@spliit.cloud](mailto:privacy@spliit.cloud) instead — see the [privacy notice](https://spliit.cloud/privacy).
- Security issues: email [security@spliit.cloud](mailto:security@spliit.cloud) and do not open a public issue.

## Connected applications

If you connected ChatGPT, Claude, or another OAuth application to your Spliit Cloud account, review its access under account settings and disconnect it there if you no longer use it. Mention the application name and when you connected it when asking for help with a connection.
